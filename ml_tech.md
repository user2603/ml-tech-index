# ML Tech Index

Reference index of the machine-learning technologies featured in the
[MCP-youtube playlist](https://www.youtube.com/playlist?list=PLyzTA8cetPdHtlGw1X8Kt7Ea4bd27ApR7),
each mapped to the original GitHub repository behind that technology.

| Technology | Repository | Main Functions |
|------------|------------|-----------------|
| OpenHands | https://github.com/All-Hands-AI/OpenHands | Open-source AI software engineering agent that writes, runs and fixes code autonomously |
| Gemini CLI | https://github.com/google-gemini/gemini-cli | Google's open-source command-line AI coding assistant built on Gemini models |
| OpenAI Codex | https://github.com/openai/codex | OpenAI's open-source command-line coding agent powered by its reasoning models |
| Qwen3-Coder | https://github.com/QwenLM/Qwen3-Coder | Alibaba's open-weight agentic coding model, with its finetuning and evaluation code |

## Excluded Technologies

- Claude Opus 4.1 — Anthropic's proprietary large language model, no original open-source repository of its own.
- Claude Code — Anthropic's closed-source CLI coding agent, no original open-source repository of its own.
- GitHub Copilot — GitHub's closed-source commercial product, no original open-source repository of its own.
- Devstral — Mistral's open-weight model is distributed through Hugging Face rather than a single original GitHub repository.
